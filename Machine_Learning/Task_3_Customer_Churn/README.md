# Task 3: Customer Churn Prediction

Objective
Build a machine learning model to predict whether a customer will churn (leave the service) based on historical customer data.

Description
This project analyzes customer behavior data and applies machine learning techniques to identify customers who are likely to churn.  
The model helps businesses improve customer retention by taking preventive actions.

Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

Dataset
- Customer churn dataset (CSV format)
- Contains customer details such as tenure, services used, and account information

Model Used
- Logistic Regression / Machine Learning Classifier
- Train-test split for evaluation

Evaluation Metrics
- Accuracy
- Classification Report
- Confusion Matrix

Results
- **Status:** Completed  
- **Accuracy:** 86%

Files Included
- `Customer_Churn_Prediction.ipynb` – Jupyter Notebook containing data preprocessing, model training, and evaluation
- `README.md` – Project documentation

Conclusion
The model successfully predicts customer churn with good accuracy.  
This project demonstrates practical application of machine learning in customer analytics and business decision-making.
