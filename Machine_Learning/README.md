Task 1: Movie Genre Classification

Objective:
Build a machine learning model to predict the genre of a movie based on its plot description.

Description:
This project applies Natural Language Processing (NLP) techniques to classify movies into
multiple genres using textual plot summaries. TF-IDF vectorization is used to convert text
data into numerical features, and a Logistic Regression classifier is trained for prediction.

Tools & Technologies:
- Python
- Pandas
- NumPy
- Scikit-learn

Dataset:
- train_data.txt
- test_data.txt

Model Used:
- TF-IDF Vectorizer
- Logistic Regression (Multi-class)

Results:
Accuracy: 57.9%

Status:
Completed
