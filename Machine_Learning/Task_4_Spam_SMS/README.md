# Task 4: Spam SMS Detection

Objective
Build a machine learning model to classify SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing techniques.

Description
This project uses text preprocessing and machine learning to detect spam SMS messages.  
TF-IDF vectorization is applied to convert text into numerical features, and a Naive Bayes classifier is used for classification.

Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

Dataset
- SMS Spam Collection Dataset (`spam.csv`)
- Contains labeled SMS messages (spam / ham)

Model Used
- TF-IDF Vectorizer
- Multinomial Naive Bayes Classifier

Evaluation Metrics
- Accuracy
- Classification Report
- Confusion Matrix

Results
- **Status:** Completed  
- **Accuracy:** 97.8%

Files Included
- `Spam_SMS_Detection.ipynb` – Jupyter Notebook with preprocessing, model training, and evaluation
- `README.md` – Project documentation

Conclusion
The model accurately classifies SMS messages as spam or ham.  
This project demonstrates the use of NLP and machine learning for real-world text classification problems.
